# Tabletop: a self-hosted D&D game

Play D&D with your friends on a server you run yourselves. One person starts the server and everyone else joins from a web browser. Nothing needs to be installed on the players' side, and there are no accounts or subscriptions.

There are two ways to play:

## 1. Adventure mode: the game is the DM

Start **Play an adventure** and the game runs the story for you. Everyone (including the host) creates a hero and plays.

- **An open world:** travel freely between locations on a world map. New places show up as you hear about them, and some roads stay locked until you find a way through.
- **Scenarios with choices:** talk your way past a bandit queen, sneak, fight, solve a fey riddle or pay up. Many choices are **skill checks**: roll a d20 plus the bonus of the hero who picks it, and beat the DC (the target number). Let your best hero try.
- **Quests:** the main quest can be solved several ways, and there are side quests, loot, gold and XP. Heroes level up to level 5. The journal tracks everything.
- **Automatic combat:** heroes take turns in initiative order and the game plays the monsters. Fighters catch a Second Wind, Rogues sneak attack, Wizards cast Fire Bolt and Magic Missile, and Clerics heal and smite. Potions can revive a fallen friend. Fights scale to your party size.
- **Resting:** rest at the inn to fully heal and get spells back. Camping in the wild heals half your HP, but something might find you. If the whole party falls, you wake up back in town with half your gold. The adventure doesn't end.
- **One screen works too:** add everyone with **+ Player on this device**. In combat the screen switches to whoever's turn it is.

The included adventure is **The Ashen Vale**: 8 locations, a main quest, 3 side quests, and 8 kinds of monsters. It takes roughly 1–2 hours and suits 2–4 heroes. Solo players can run two or three heroes from one screen.

### Art, effects and sound

- **Every location has its own illustrated scene** with live weather: falling ash (until you ring the bell), fog, fireflies, embers, marsh wisps, crypt drips and chimney smoke.
- **Board-game pieces:** monsters are cards with art, an armor badge and an HP bar. Heroes have portrait medallions, and the world map is a parchment board with place medallions.
- **Character pictures:** upload any picture in the **Character** tab or while creating a hero. It's cropped and resized for you, then shown on hero cards and on map tokens in both modes.
- **Effects:** an animated d20 for every skill check, slashes and spell flashes on hits, floating damage and heal numbers, and banners for combat, victory, level-ups and defeat. Sound effects are generated by the browser, and the **Sound** button in the scene banner mutes them. Animations are toned down if your device is set to reduce motion.

**Using your own pictures:** put an image in `public/art/` and give a location `image: '/art/your-picture.jpg'` in the adventure file to replace its drawn scene. Wide pictures (about 1600×600) work best. Public-domain landscape paintings, for example from Wikimedia Commons, make great backgrounds. Monsters, items and places can use any icon from [game-icons.net](https://game-icons.net). Add the icon to `scripts/import-icons.js` and run it, as described in that file.

Icons are by Lorc, Delapouite, Skoll and other artists at game-icons.net (CC BY 3.0); see [`public/art/CREDITS.md`](public/art/CREDITS.md). The scenes were drawn in code for this project.

### Writing your own adventure

Adventures are plain JavaScript data files in `adventures/`. Copy `adventures/ashen-vale.js`; the comment at the top explains the format: locations, paths, scenes, choices, checks, outcomes, monsters and items. Then add your file to the list at the top of `adventure.js`, and it shows up in the lobby. Run `npm test` afterwards, and add a playthrough test like the ones in `test/adventure.test.js`.

## 2. Free tabletop: a person is the DM

Start a **Free tabletop** game when one of you wants to run the session. You get a virtual tabletop, without the automatic story:

- **Shared battle map:** upload any map image, line up the grid and zoom/pan. Moving a token shows the distance in feet.
- **Tokens:** players move only their own. The DM can move everything, hide monsters from players, resize tokens and assign them to players.
- **Dice and chat:** dice buttons or commands (`/r 1d20+5 Stealth`). Advantage and disadvantage, keep/drop (`4d6dl1`), and secret rolls only the DM sees. All rolls happen on the server, so nobody can fake them.
- **Character sheets:** ability scores with auto modifiers, one-click checks and saves, HP with a Damage/Heal button, inventory and notes.
- **Initiative tracker:** players roll with their DEX + bonus. The DM adds monsters and steps through turns.
- **Pings:** double-click the map to point at something.

Both modes save games to disk, so you can stop the server and pick up next session.

## Running it

You need [Node.js](https://nodejs.org) 18 or newer on the computer that hosts the game.

```bash
cd dnd
npm install
npm start
```

The server prints the addresses to open:

```
  On this computer:   http://localhost:3000
  On your network:    http://192.168.1.23:3000
```

1. **Host:** open the address, enter your name and click **Play an adventure** (or **Free tabletop** to be the DM).
2. Click **Copy invite** in the top bar and send the link to your players. You can also just tell them the 6-letter code.
3. **Players:** open the link, enter a name and click **Join**.

To run the game from another device (for example, a tablet at the table), open the **Map** tab and use **Copy DM link**. Keep that link private, because anyone who has it is the DM.

## Playing on one screen (hot-seat)

Everyone can also play around a single laptop or TV, with no other devices needed:

1. The DM creates the game as usual.
2. For each player at the table, click **+ Player on this device** and type their name.
3. A **Playing as** bar appears. Click a name (or press **1–8**) to switch to that person's view: their sheet, their tokens and their secret rolls. In a player's view, the DM's hidden tokens and secret rolls are not shown.
4. Leave **Switch on each initiative turn** ticked. When the DM clicks **Next turn**, the screen switches to whoever is up. On a monster's turn it switches back to the DM.

Each player on the screen still counts as a real player, so you can mix both ways of playing. For example, two friends can share a laptop while others join from their own devices. Your list of players on the device is remembered for the next session.

## Letting friends connect

| Situation | What to do |
|---|---|
| Everyone on the same Wi-Fi | Share the `On your network` address. If it doesn't load, allow Node.js through the host's firewall. |
| Playing online (easiest) | Use [Tailscale](https://tailscale.com) (free). Everyone installs it and joins your tailnet, then opens `http://<host's tailscale IP>:3000`. |
| Playing online (no install for players) | Run `cloudflared tunnel --url http://localhost:3000` ([Cloudflare quick tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/)) and share the `https://…trycloudflare.com` link it prints. You get a new link each time. |
| Always-on server | Forward port 3000 on your router, or run it on any cheap VPS. Put it behind HTTPS (Caddy or nginx) if it's on the open internet. |

## Settings

Set these as environment variables, for example `PORT=8080 npm start`:

| Variable | Default | Meaning |
|---|---|---|
| `PORT` | `3000` | Port to listen on |
| `HOST` | `0.0.0.0` | Address to bind (`127.0.0.1` = only this computer) |
| `DATA_DIR` | `./data` | Where games and uploaded maps are saved |

To wipe all games, stop the server and delete the `data` folder.

## Tips for the table

- **Line up a map:** if your map image is 30 squares wide and 20 tall, set Columns 30 and Rows 20 in the **Map** tab.
- **Keyboard:** select one of your tokens, then use the arrow keys to move it or Delete to remove it.
- **Type `/help`** in chat for all the dice commands.
- **Player names are tied to the browser.** If someone switches devices they show up as a new player, and the DM can reassign their token.

## Development

```bash
npm test   # dice tests, a multiplayer session against the real server, full adventure
           # playthroughs, and a fuzz test of thousands of random adventure actions
```

| File | What's in it |
|---|---|
| `server.js` | HTTP + WebSocket server, permissions, saving to disk |
| `adventure.js` | Adventure engine: exploration, checks, quests, levelling and automated combat |
| `adventures/` | Adventure content (story, map, monsters) |
| `dice.js` | Dice expression parser |
| `public/fx.js` | Weather particles, combat effects, dice animation and sounds |
| `public/art/` | Location scenes (`scenes.js`), icons and credits |
| `scripts/import-icons.js` | Copies icons from a game-icons.net clone |
| `public/` | The web app (plain HTML/CSS/JS, no build step) |

The only dependency is [`ws`](https://github.com/websockets/ws).
